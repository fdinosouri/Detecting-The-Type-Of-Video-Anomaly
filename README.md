# UMIL and VideoMAE Experiment for Video Anomaly Detection

This repository is a research and practice project focused on Detecting The Type Of Video Anomaly using UMIL and VideoMAE.

The main goal of this project was to study the structure of UMIL, understand how video feature extraction works, and explore how a VideoMAE-style backbone could be integrated into the pipeline.

## What I Worked On

- Studied the UMIL project structure
- Reviewed configuration files for UCF-Crime experiments
- Tested the training and running process on a local Windows environment
- Explored the model loading process and backbone structure
- Investigated how VideoMAE can be used as a feature extractor
- Documented the steps required to run the project

## Technologies Used

- Python
- PyTorch
- MMCV
- UMIL
- VideoMAE
- UCF-Crime dataset configuration
- VS Code
- PowerShell
